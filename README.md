# VRChat Multitool

Приложение MicroRivnexo для VRChat на Windows x64. Здесь публикуются официальные установщики и обновления. Актуальная версия — [2.3.0](https://github.com/Rosecod337/VRChatAdminTools/releases/tag/v2.3.0).

[Скачать для Windows](https://vrchatadmintools.ru/download) · [Личный кабинет](https://vrchatadmintools.ru/account) · [Discord](https://discord.gg/Cg2CqMcnY3) · [Telegram](https://t.me/VRChatMultitool)

## Возможности и тарифы

- **Личный режим — бесплатно.** Локальный поиск и история, центр приватности и переводчик для VRChat. Переводчик выводит перевод в чатбокс игры и показывает субтитры к речи других игроков, в том числе в отдельном окне для VR. Модели работают на компьютере пользователя.
- **Командный доступ — 70 ₽ за 30 дней на одного модератора.** Для совместной работы с заметками об игроках и командным журналом.
- **Эмуляция трекеров — 100 ₽ за 30 дней или 400 ₽ бессрочно.** Доступ оформляется отдельно. Поддерживаются VRChat OSC и SteamVR.

## Вход в приложение

В VRChat Multitool нажмите «Войти через кабинет» и подтвердите вход в браузере. Учётную запись VRChat при необходимости привяжите отдельно.
