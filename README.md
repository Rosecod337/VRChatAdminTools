# VRChat Admin Tools

Официальные установщики и обновления VRChat Admin Tools для Windows.

## Версия 2.2

Переводчик для VRChat, бесплатно для всех: перевод чата и голоса в чатбокс игры, субтитры к речи других игроков (в том числе отдельное окно для VR), прямой перевод с китайским через Tencent Hy-MT2 и разговорник частых фраз. Модели работают на компьютере, речь и текст на сервер не отправляются.

Также в 2.2: уведомления поверх экрана со своими звуками и понятный редактор правил уведомлений, фоновый режим с автозапуском, статус в Discord и интерфейс на английском, японском и китайском.

Бесплатно доступны локальный поиск, история, центр приватности и переводчик. По ключу — фотоатлас, маршруты, отчёты, правила уведомлений, подготовка сессии, диагностические записи, еженедельная сводка, экспорт доказательств и командный журнал.
